# Higher pension / PoHW

Curated issue-date history using EPFO-hosted original PDFs and physical page mapping.
Missing originals remain explicit gaps. Source dates come from the documents.

- Supreme Court judgments, scheme amendments, deadline extensions and subsequent litigation are not fully collected as originals.
- The 18 January 2025 clarification original could not be fetched; this inventory cannot settle pro-rata calculation or trust-rule issues.
- July 2025 audit targets are administrative deadlines, not new member application windows or commencement dates.
- General EPF paragraph 26(6) enrolment and JD profile correction are separate scopes.

Run `python policy_history.py --policy-name higher_pension --as-of 2025-10-13 --query "Higher pension / PoHW"`.
