# Official Language implementation (check points, annual programme, bilingual practice)

Seventeen English-titled Official Language Division circulars (2010-2019): check points for the Official Language Policy of the Union (2010, 2011, 2012, 2019), compliance of the annual Hindi programme (2011, 2012), quarterly reports and inspection, bilingual website material, standard letter head, use of Hindi on computers, simple Hindi translation, the Rs. currency symbol and the 2015 arrangement for using Official Language Wing officers.

This is a partial history: the Hindi-titled circulars (Hindi teaching scheme, incentives, awards and later circulars) are not included. Issue dates follow the issuer listing because the scan headers are not legible. No supersession between circulars is asserted.
