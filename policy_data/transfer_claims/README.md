# Transfer claims

Curated issue-date history using EPFO-hosted original PDFs and physical page mapping.
Missing originals remain explicit gaps. Source dates come from the documents.

- Earlier OTCP/auto-transfer instructions and exempted-trust transfer rules are not fully collected.
- The January 2025 employer-routing original is unavailable; exact qualifying categories require supplementary evidence.
- Overlapping service is not by itself disqualifying for transfer. This does not establish EPS entitlement or double-counting of service.

Run `python policy_history.py --policy-name transfers --as-of 2025-10-13 --query "Transfer claims"`.
